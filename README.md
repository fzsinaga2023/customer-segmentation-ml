# Bank Customer Segmentation ML Project

Proyek Machine Learning untuk melakukan segmentasi nasabah berdasarkan pola transaksi menggunakan algoritma **K-Means Clustering**.

## 📊 Hasil Analisis
Model berhasil membagi nasabah menjadi 3 segmen utama:
- **Klaster 0 (Aspiratif):** Profil nasabah dengan saldo rendah namun aktif.
- **Klaster 1 (Stagnan):** Nasabah dengan perilaku transaksi stabil/konsisten.
- **Klaster 2 (Potensial):** Nasabah dengan kondisi keuangan paling sehat.

## 🛠 Tech Stack
- Python
- Scikit-Learn (K-Means, StandardScaler)
- Pandas & Matplotlib (Data Analysis & Visualization)
